# Public Transport Network Analysis

## Introduction

This project analyzes the public transport networks of Canberra, Detroit, Paris, and Rome using graph theory and temporal network methods. The study compares daily and weekly transport data to examine network structure, traffic patterns, accessibility, and computational performance.

## Project Objectives
The analysis focuses on five main questions:
1. Which stops have the largest number of departures?
2. Which nodes have the highest out-degree?
3. What is the diameter of the largest connected component?
4. How does the number of connections change over time?
5. How many stops can be reached within 30 minutes, one hour, and two hours?

## Main Files

- `code_py.py`: Python code for graph construction and analysis.
- `Publi Trasport Network Analysis.pdf`: complete project report
